## 现在的默认学习方式

从现在开始，默认不再继续线性生成“下一课”。

默认学习方式改为：

1. 按导航复习已有课程
2. 在主项目中实现对应能力
3. 做阶段性复盘
4. 只在真实项目卡点上补新内容

这意味着：

> 课程是地图，项目是战场，仓库是作品集。
