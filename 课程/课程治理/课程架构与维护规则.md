# 课程架构与维护规则

## 唯一主线

课程固定为 8 个模块、32 节主课。每模块包含 `模块导学.md`、4 份连续编号课程和 `模块验收与面试.md`；完成教材精写的模块另含 `模块练习参考答案.md`。RAG 与多 Agent 各有 4 节选修，不计入主线编号。

## 教学优先级

1. 先提出真实问题，再给术语。
2. 先手工画 Think–Act–Observe 轨迹，再写代码。
3. 每课只增加一个主要概念和一个可验证代码增量。
4. 每课包含运行命令、预期输出、错误排查、基础实验、进阶挑战和 5 个自测问题。
5. 模块检查点用于对照和恢复，不能替代学习者亲手实现。
6. 禁止用脚本批量覆盖课程正文；脚手架只允许创建目录，教材必须逐课人工精写并通过质量测试。

## 教材候选版与稳定版门槛

正文 3000–5000 个中文字符仅是建议阅读量，不是完成判据；统计时应排除 fenced code、链接地址与 Markdown 标记。短课可以少于建议值，长课也不能用重复文字凑数。

进入“候选版”必须形成完整问题链、概念推导、至少两个具体案例、两个常见误区、可执行示例、失败路径、基础与进阶练习、五个独立自测问题和对应答案。进入“稳定教学版”还必须有命令复跑记录、最终实现契约映射、讲师语义复核、至少一次试讲反馈和独立对抗审查。任何单一的字数、文件数或测试绿灯都不能独立证明教材完成。

## 课程完成标准

“完成”必须同时具备原理复述、代码运行、故障定位和设计答辩。只读过文档、复制最终代码或只展示成功 Demo 都不算完成。

## API 与事实核验

OpenAI Responses API 是具体教学实现，LLM 抽象在模块 4 引入。API 课程必须记录最后核验日期和官方来源，不声明永久默认模型。在线调用仅为选做，离线必修路径不得依赖密钥、网络或费用。

- 最后核验日期：2026-07-17
- [Function calling](https://developers.openai.com/api/docs/guides/function-calling)
- [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)

## 历史与新增规则

历史版本只读归档，不维护第二套入口。主线不再增加 L33；新内容优先补充现有课程，只有具备独立问题、代码实验和评测基线时才能新增选修模块。

## 自动验证

```powershell
cd agent-from-scratch
python -m pytest -q
```

测试必须检查 32 课结构、固定教学章节、选修模块、历史映射、链接、UTF-8、代码检查点、正式 Runtime 契约和 wheel 分发。自动测试只能证明机器可验证部分；讲师语义复核与试讲记录必须另行留痕。
