# 选修：RAG 与外部知识实验

## 定位

RAG 不是 Agent 的默认组成部分。只有固定评测表明“缺少仓库外知识”是主要失败原因时，才进入本专题。

## 进入条件

- M07 的 20 题基线已运行并保存结果。
- 已区分仓库代码搜索失败与外部知识缺失。
- 有可授权、可更新、可追溯的数据源。
- 能定义检索命中、答案正确和成本变化的指标。

## 实验路径

1. 建立无 RAG 基线。
2. 对文档切分、元数据和更新策略做最小设计。
3. 检索结果以 ToolResult 或明确上下文 adapter 注入。
4. 记录来源，避免模型把检索内容当系统指令。
5. 比较成功率、延迟、上下文长度和错误引用。

## 与 Session、Memory 的边界

- Session 保存交互历史。
- Memory 保存经过选择的长期用户或任务信息。
- RAG 按当前问题检索外部知识。

三者可以协同，但不能共用一个无限增长的向量库代替所有状态设计。
