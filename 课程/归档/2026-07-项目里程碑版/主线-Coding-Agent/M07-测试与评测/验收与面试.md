# M07 验收与面试

## 产物验收

- `python -m pytest -q` 全部通过。
- `coding-agent-eval` 输出 `valid_cases: 20`、`mode: offline_protocol` 和完整指标。
- E2E 测试使用临时工作区，不修改真实仓库。
- 在线测试不属于默认测试路径。

## 代码讲解

选择同一能力的单元、集成和 E2E 测试各一个，说明它们捕获的失败为何不同。再解释评测任务的输入、验收器和指标如何组成可比较实验。

## 精选面试题

1. Agent 测试为什么不能只比较最终文本？
2. FakeLLM 与 Mock SDK 各适合测试哪一层？
3. 契约测试应锁定字段还是锁定完整序列化快照？
4. 如何测试具有随机性的模型行为？
5. 成功率相同但工具调用翻倍，能否认为没有回归？
6. LLM-as-a-judge 有哪些偏差和适用边界？

## 故障分析

1. 单元测试全过但真实仓库修改失败，缺少哪类测试？
2. 评测成功率突然提升，同时任务文件被修改，结论为什么无效？
3. 测试偶发超时，如何区分产品问题和测试设计问题？

## 设计取舍题

设计一套 PR 质量门槛，说明哪些检查必须阻断合并，哪些指标只做趋势观察，以及在线烟雾测试何时运行。

## 现场任务

先写一个失败的边界测试，再完成最小实现并运行 `python -m pytest -q`。答辩重点是测试为何能证明行为，而不是代码行数。

## 通过标准

能区分确定性测试与统计评测，并能用指标发现“答案正确但成本明显退化”的问题。
