# M01 验收与面试

## 产物验收

- 能用 `python -m pip install -e ".[dev]"` 安装。
- 能用 `python -m pytest -q` 离线运行测试。
- 能指出模型配置、SDK 适配、标准响应和 Runtime 的文件边界。
- 能证明测试期间没有真实网络调用。

## 代码讲解

用 5 分钟完成以下讲解：

1. 为什么采用 `src` 布局而不是继续把模块放在项目根目录。
2. `BaseLLM` 为什么返回 `LLMResponse`，而不是 OpenAI Response 对象。
3. `FakeLLM` 如何让 Agent Loop 可重复测试。
4. 配置优先级和密钥安全如何处理。

## 精选面试题

### 接口与依赖

1. 抽象 LLM 接口的收益和成本分别是什么？
2. 为什么“支持多个模型”不等于把所有供应商能力取交集？
3. `raw_response` 可以保留，为什么 Runner 仍不应读取它？
4. editable install 与直接修改 `PYTHONPATH` 有何区别？

### 故障分析

1. 测试在仓库目录能过，打包安装后导入失败，优先检查什么？
2. 没有 API Key 时单元测试失败，说明哪个边界设计错了？
3. SDK 升级后 `response.output` 结构变化，修改应集中在哪里？

## 设计取舍题

比较“Runtime 直接调用 OpenAI SDK”和“通过 `BaseLLM` 适配”的可测试性、供应商能力保留、维护成本。答案必须结合本项目代码，而不是只背设计模式。

## 现场任务

给 `FakeLLM` 增加一个预设失败，再用 `python -m pytest -q` 证明错误不会被伪装成成功结果。

## 通过标准

不仅能运行命令，还能从代码中定位每个边界，并说明一个替代方案为什么没有被采用。
