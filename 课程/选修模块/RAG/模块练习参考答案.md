# RAG 模块练习参考答案

## R01 基线

项目私有端口、当前规范和最新故障记录需要外部证据；当前仓库代码优先用 read/search Tool；当前对话用 Session；长期用户偏好才考虑受治理 Memory。无证据时拒答不是失败，前提是评测标注该问题确实需要外部知识。

## R02 检索

`chunk_size=6, overlap=2` 对 `abcdefghij` 产生 `abcdef`、`efghij`。倒排评分是 Query token 与 Chunk token 交集数量；同分按 chunk id 排序。改用 Embedding 前，应先在固定 Query 集上证明 Recall 或 MRR 提升。

```python
chunks = chunk_document(Document("guide.md", text), 500, 50)
results = InvertedIndex(chunks).search("Acme port", top_k=3)
```

## R03 来源安全

检索文本保留原文并放在 `untrusted=true` source block；不能进入 System Instructions。关键词检测只能作为告警，真正防线是角色隔离、Workspace、审批、最小 Tool 权限和输出引用。

## R04 评测

Rankings `[[a,b],[x,c],[z]]` 对 relevant `[{a},{c},{missing}]` 的 Recall@1 为 1/3，Recall@2 为 2/3。若 Top-K 命中但答案错，应检查 Context Builder 和 Generator；若未命中才优先调整切分、tokenizer 或评分。

## 边界速查

- RAG：可重建的外部文档索引。
- Session：当前对话的时间序列。
- Memory：跨会话长期事实，需要同意、更新和删除机制。
- Coding Tool：当前工作区的真实文件与命令结果。

不要把四类数据无差别写入一个向量库。
