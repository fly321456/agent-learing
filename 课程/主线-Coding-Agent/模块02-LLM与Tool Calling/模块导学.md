## 学习规则

先运行离线脚本，再决定是否做在线实验。不要把 API Key 写入文件；不要把一次 Function Calling 称为 Agent Loop；每次必须检查第二次请求是否保留原始 output 和相同 call ID。

## 完成标准

能够解释 Instructions、Message、Context 的边界；能够区分 `output_text` 与 `response.output`；能够手绘两次模型调用；能够定位非法 JSON、未知 Tool 和 call ID 错配；通过 [模块验收与面试](模块验收与面试.md)。
