# 模块 5 练习参考答案

## L17 路径与读取

验证路径时应比较 resolve 后的 Path 包含关系，不做字符串 startswith。多只读根目录可保存为已 resolve 的列表，目标只要 relative_to 任一根成功即可；仍不接受任意绝对路径。

```python
text = read_file(context=context, path="notes.md", start_line=2, end_line=3)
assert text.endswith("\n")
```

## L18 搜索限制

宽 query 被截断后，优先缩小 path、glob 或使用完整符号名，而不是无限增加 max_results。单行限制可在 append 前裁剪，并增加 `[line truncated]` 标记。零匹配返回空 output、status=success；越界或参数错误返回 status=error。

## L19 补丁与验证

非唯一 old_text 应补充函数签名和相邻行，使其成为唯一片段。命令验证必须断言 `status` 与 `exit_code`，不能搜索 stdout 中的“passed”字样。写前/写后 SHA-256 可进入 ToolResult data，帮助审计实际版本。

```python
patch = manager.execute(ToolCall("p1", "apply_patch", args), approved_context)
assert patch.status == "success"
test = manager.execute(ToolCall("t1", "run_command", test_args), approved_context)
assert test.status == "success"
```

## L20 审批策略

最小白名单回调应比较 argv 元素而非拼接字符串：只允许 `sys.executable, -m, pytest` 前缀，其他命令拒绝。审批记录至少保存 run_id、call_id、Tool 名、参数摘要、决定和时间。一次性 token 应绑定参数哈希，参数变化必须重新审批。

## 综合排障

读取失败先查路径与编码；搜索噪声先收窄 query；补丁失败先重新读取，不要模糊替换；命令非零保留 stdout/stderr；timeout 不盲重试；denied 不换名字绕过审批。安全边界由 Runtime 执行，不能靠模型自律。
