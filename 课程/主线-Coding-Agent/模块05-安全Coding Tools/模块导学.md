# 模块 5 导学：安全 Coding Tools

模块 4 的 Runtime 已会调用通用 Tool，但 Coding Agent 的真正风险来自文件与进程副作用。本模块坚持一个原则：**模型提出行动，代码决定边界，用户批准高风险副作用，结果必须可解释。**

```text
L17 工作区与 UTF-8 读取
  → L18 受限仓库搜索
  → L19 唯一精确补丁与命令验证
  → L20 风险审批、拒绝与超时
```

完成后，你将能在临时仓库执行“读、搜、改、验”，并证明越界路径、非唯一补丁、审批拒绝、非零命令和超时都不会伪装成功。

```powershell
cd agent-from-scratch/course-checkpoints/05-coding-tools
python steps/l17_read_boundary.py
python steps/l18_search_limits.py
python steps/l19_patch_and_verify.py
python steps/l20_approval_and_timeout.py
python demo.py
```

本模块只使用 argv 命令与 `shell=False`，所有写入和执行默认审批，没有审批回调时 fail closed。所有示例使用临时目录，不修改真实课程仓库。学习后先独立完成故障实验，再查看 [模块练习参考答案](模块练习参考答案.md) 和 [模块验收与面试](模块验收与面试.md)。
