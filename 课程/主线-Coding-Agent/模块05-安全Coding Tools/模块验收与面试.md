# 模块 5 验收与面试：安全 Coding Tools

## 自动验收

```powershell
cd agent-from-scratch
python -m pytest -q tests/test_course_module5.py
python -m compileall -q course-checkpoints/05-coding-tools
python course-checkpoints/05-coding-tools/demo.py
```

## 功能检查

- 严格 UTF-8 读取，越界路径和符号链接逃逸被拒绝。
- 搜索有 glob、目录和结果上限，跳过二进制与 `.git`。
- Patch 只允许恰好一次匹配，失败不改文件。
- Command 使用 argv、`shell=False`、工作区 cwd、结构化退出码。
- write/execute 默认审批；无回调拒绝；Timeout 独立于 error。

## 代码讲解

请沿 `ToolCall → ToolManager → Approval → Handler → ToolResult` 讲解一次 Patch 和一次 Command。指出路径边界、审批边界、时间边界分别在哪一行生效，以及为何顺序不能颠倒。

## 故障注入

1. 读取 `../outside`。
2. 搜索结果超过上限。
3. old_text 出现两次。
4. 审批回调拒绝。
5. 命令 exit 3。
6. 命令超过 timeout。

## 设计取舍与面试题

1. 为什么不能依靠 Prompt 保证路径安全？
2. Path containment 为什么优于字符串前缀？
3. 搜索结果过多如何影响 Agent？
4. 精确补丁如何降低并发覆盖风险？
5. shell=False 解决什么、没解决什么？
6. denied、error、timeout 为什么要区分？
7. 为什么没有审批回调应 fail closed？
8. 验证失败后是否自动回滚，取决于什么？

## 通过标准

专项测试全部通过；能在临时仓库完成读、搜、改、验；能解释每个失败状态的恢复动作；能证明真实工作区未被示例修改。只演示成功路径不算通过。
