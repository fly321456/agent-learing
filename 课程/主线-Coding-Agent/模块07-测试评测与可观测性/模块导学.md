# 模块 7 导学：测试、评测与可观测性

前六个模块让 Agent 能运行、安全修改、保存和恢复；本模块回答更严格的问题：我们如何证明它今天仍正确？重构后是否退化？失败时能否定位到具体步骤？

```text
L25 FakeLLM 与小型离线单元测试
  → L26 Event 契约、真实组件集成、临时 Git E2E
  → L27 20 条固定任务与动态回归指标
  → L28 JSONL Trace 与逐 Run 故障定位
```

完成后应能区分“协议回放 20/20”和“真实模型成功率”；能故意破坏一条 actual Tool 序列并看到指标下降；能从 Trace 的 run_id、sequence、step 和 call_id 定位失败。

```powershell
cd agent-from-scratch/course-checkpoints/07-testing-evaluation
python steps/l25_fake_llm.py
python steps/l26_contract_e2e.py
python steps/l27_twenty_case_eval.py
python steps/l28_jsonl_trace.py
python demo.py
```

所有默认验收离线运行。临时 E2E 使用真实 Git、文件和 pytest，但不触碰学习者仓库；评测指标由 executor 结果计算，不允许静态 `passed=True`。学习后查看 [模块练习参考答案](模块练习参考答案.md)，再完成 [模块验收与面试](模块验收与面试.md)。
