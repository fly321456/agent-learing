- `cases.json` 恰好 20 个唯一任务，覆盖五类能力。
- 指标记录成功率、Tool 次数、steps、耗时和失败分类。
- 故意错一条 actual sequence 后必须变为 19/20。
- JSONL Trace 行数、顺序与 Event 一致。

## 设计取舍与面试题

1. Fake 与 Mock 有何区别？
2. 为什么真实模型不进入默认 E2E？
3. Event 契约为何超出类型检查？
4. 20/20 离线协议结果为什么不能宣传为模型成功率？
5. 成功率相同为何还要比较 Tool calls 和 steps？
6. JSONL 相比 JSON 数组有何优点？
7. Trace 数据如何截断与脱敏？
8. 如何从聚合失败定位单个 Run？

## 通过标准
