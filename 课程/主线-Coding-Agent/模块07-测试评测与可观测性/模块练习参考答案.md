# 模块 7 练习参考答案

## L25 FakeLLM

请求快照应复制 messages 容器，避免 Runner 后续 append 污染旧请求。默认响应耗尽抛错；只有测试无限 Tool Loop 时显式 repeat_last。断言 `RunResult`、call_id 和下一轮 Observation，不断言私有方法调用顺序。

## L26 契约与 E2E

Event Contract 至少验证 sequence 连续、run_id 唯一、首尾事件合法。临时仓库 E2E 使用真实 Path、Git 和 subprocess，Fake 掉外部模型。Bug 应在最低可复现层补测试，再保留一条主链 E2E 防止组件连接退化。

```python
result = run_repository_e2e(tmp_path)
assert result.actions == ["read", "search", "patch", "test"]
assert result.passed
```

## L27 评测

证明指标动态的最简单方式是失败注入：让一个 case actual_tools=[]，断言 passed=19、success_rate=.95、failures 中出现 tool_sequence。进一步应按 category 汇总，并用文件状态与测试退出码作为 outcome validator。

## L28 Trace

JSONL 每行独立 JSON，按 sequence 读取。`validate_tool_pairs` 可用 call_id 字典记录 called，再拒绝重复 completed 或无 called 的 completed。大型 output 在 Event 产生前截断，并写 `truncated=true`；密钥与环境变量必须脱敏。

## 综合排障

单测失败先看稳定边界；E2E 失败看 actions 和 test_output；评测退化先按 category 找 case；最后用 run_id 打开 JSONL Trace。不要第一步就改 Prompt，先确认 Context、Tool、call_id、审批和终止协议。
