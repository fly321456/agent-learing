## 功能检查

- CLI Event 展示不修改 Runtime，审批空输入默认拒绝。
- 最终答案与进度分别使用 stdout/stderr 语义。
- MCP Server 可由 `FastMCP.list_tools()` 发现。
- MCP 恰好暴露 `read_workspace_file`、`search_workspace`。
- MCP 读取受 Workspace、UTF-8 和结果上限约束。
- checkpoint 可构建一个 wheel，并支持 editable install。
- README 明确离线默认、在线条件、评测口径和安全限制。

## 故障注入

1. 审批直接回车，确认拒绝。
2. 请求 `../outside.md`，确认 Server 拒绝。
3. 意外注册 Patch Tool，确认名称集合测试失败。
4. 在 stdio stdout 打印调试文本，解释协议风险。
5. 改错 console script 或 package discovery，确认构建/安装失败。
6. 删除 MCP `<2` 上界，说明未验证大版本风险。
