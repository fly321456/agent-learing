# 模块 8 导学：CLI、MCP 与作品化

这是 32 节主线的交付模块。前七个模块已经形成可运行 Runtime、安全 Tool、状态恢复和评测系统；本模块不再扩张核心能力，而是把它们变成用户能操作、其他客户端能连接、评审者能安装验证的作品。

```text
L29 CLI：Event 展示、stdout/stderr、人工审批
  → L30 MCP：协议标准化范围与信任边界
  → L31 FastMCP：只读 Workspace Server
  → L32 发布：wheel、editable、README 与最终挑战
```

完成后，你应能证明 CLI 与 Runtime 解耦；能解释 MCP 不等于 Agent；能从 SDK 可见视角验证只有两个只读 Tool；能在临时目录构建 wheel 和 editable install。

```powershell
cd agent-from-scratch/course-checkpoints/08-cli-mcp-final
python steps/l29_cli_events_approval.py
python steps/l30_mcp_boundaries.py
python steps/l31_fastmcp_read_only.py
python steps/l32_package_release.py
python demo.py
```

MCP 教材最后核验日期为 2026-07-14，依赖范围 `mcp>=1.27,<2`。Server 默认 stdio，只暴露 read/search；Patch 与 Command 继续留在本地审批 Runtime。在线 OpenAI 调用不是默认验收。

学习顺序仍是先画边界、运行步骤、阅读代码、注入失败，最后查看 [模块练习参考答案](模块练习参考答案.md) 并完成 [模块验收与面试](模块验收与面试.md)。
