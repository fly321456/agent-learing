# 模块 8 练习参考答案

## L29 CLI

Event formatter 应是纯函数，未知事件返回 None。stdout 只输出最终答案，stderr 输出进度和审批。审批只有显式 y/yes 为真，EOF、空输入和其他文字都按拒绝处理。`--json` 模式应全程输出结构化 JSON，不能夹人类提示。

```python
assert request_approval("run_command", {}, lambda _: "") is False
assert request_approval("run_command", {}, lambda _: "yes") is True
```

## L30 MCP 边界

MCP 标准化发现、Schema、调用、结果、Transport 和生命周期；Agent Runtime 仍负责 Instructions、Loop、审批、Session、Checkpoint 和任务成功。MCP SDK 对象应在 Adapter 转成 ToolCall/ToolResult，Runner 不直接依赖它。

## L31 FastMCP

测试应调用 `await server.list_tools()`，断言名称集合恰好为 read/search。Workspace 在 Server 启动时闭包绑定，Tool 参数不能覆盖根目录。若增加 max_results，应同时设置服务端硬上限，不能完全信任客户端值。

```python
tools = asyncio.run(server.list_tools())
assert {tool.name for tool in tools} == {
    "read_workspace_file", "search_workspace"
}
```
