# 模块 03 练习参考答案

## L09 Loop

三轮仓库脚本应预设 list、read、finish 三个 Response。测试重点不是打印文本，而是断言第三次 `model.requests` 中同时存在前两次 Tool Output。`on_step` 应在 Trace 追加后调用，不能替代最终累计 Trace。

```python
assert result["steps"] == 3
assert result["finish_reason"] == "completed"
assert len(model.requests[2]) > len(model.requests[1])
```

## L10 Registry

新增工具只修改 Registry，不修改 `run_agent`。除零应由 handler 抛错，再由 `execute_tool` 转成 status=error。工具描述与 handler 可以封装成字典，但模块 4 才引入正式 ToolSpec。

```python
TOOLS["divide"] = lambda left, right: str(left / right)
```

## L11 多 Tool

同轮调用同一 calculator 两次时必须使用不同 call ID。结果使用列表保持顺序，不能按 name 建字典覆盖。一个调用失败后，当前教学策略继续执行其他独立调用。

```python
assert [item["call_id"] for item in result["tool_results"]] == ["c1", "c2"]
```

## L12 错误与终止

“读取失败后列目录”需要 Tool error Observation 后再由下一模型响应请求 list。若增加 decision_error，应在 `model.generate` 抛异常时返回 Run 级原因，不能伪造 ToolResult。

```python
assert result["answer"] == ""
assert result["finish_reason"] == "max_steps"
assert all(item["status"] == "success" for item in result["tool_results"])
```
