# 模块 01 Agent 核心认知导学

> 状态：教材候选版，待讲师语义复核与试讲。建议用 2 周完成，每周 2 课；每课 60–90 分钟。

## 为什么先学心智模型

初学 Agent 最常见的困难不是不会调用 API，而是过早接触框架后，只会照抄 `Agent(...)` 和 `Runner.run(...)`，却说不清工具失败后数据去了哪里、为什么还要下一轮、什么时候应该停止。模块 1 暂时不用真实 LLM，把所有轨迹做成确定性离线程序，先看清 Agent 的骨架。

完成本模块后，你应能用自己的话解释：Agent 不等于聊天机器人，不等于一次 Tool Calling，也不等于完全自治；Agent 的关键是目标驱动的“决策—行动—观察”闭环。

## 学习路径

1. [L01 什么是 Agent](L01-什么是Agent.md)：比较 Single-shot、Workflow 与 Agent，建立闭环判断标准。
2. [L02 Agent 四要素](L02-Agent四要素.md)：拆解 LLM、Tool、Loop、Environment 的职责与边界。
3. [L03 Agent 与 Workflow](L03-Agent与Workflow.md)：学会判断什么时候不该使用 Agent。
4. [L04 Think–Act–Observe](L04-手工走一遍Think-Act-Observe.md)：完成失败可恢复、停止原因明确的模块最终 Agent。

不要跳过 L01、L02 直接抄 L04。前两课故意保留缺陷，学习任务就是通过运行和故障实验推导下一步设计。

## 每课学习节奏

1. 先不看代码，回答课程开头的问题链。
2. 手工写出你预测的 Decision、Action、Observation。
3. 阅读完整代码，标出每条轨迹由哪一行产生。
4. 运行脚本并对照预期输出。
5. 完成至少一个故障实验，再做基础练习。
6. 最后回答 5 个自测问题；答不清时回到对应轨迹，而不是背定义。

## 模块完成标准

- 能在白纸上画出 Task → Decision → Action → Observation → Decision → Finish。
- 能解释 `ScriptedLLM` 为什么不是伪装的真实模型，以及它为何适合第一模块。
- 能从 Trace 区分工具成功、工具失败、未知工具、正常完成和步骤耗尽。
- 能根据可预测性、成本、审计、安全和任务不确定性选择 Workflow 或 Agent。
- 能通过 [模块验收与面试](模块验收与面试.md)，并运行全部离线测试。
