# 模块 6 导学：Session、上下文与可靠性

模块 5 已让 Agent 安全地产生副作用，但长任务还会遇到四类状态问题：用户说“继续”时没有历史；历史无限增长；进程中断后重复 Tool；暂时性错误与确定性错误被同样处理。

```text
L21 Session / Turn / Run 身份与持久化
  → L22 Context 预算、完整消息裁剪与摘要
  → L23 Checkpoint 恢复与副作用去重
  → L24 Config、错误分类与有限 Retry
```

完成模块后，你应能解释 Session 与 Checkpoint 的差异；能证明 Context 裁剪不删除源历史；能用相同 call_id 恢复而不重复副作用；能让确定性错误只执行一次。

```powershell
cd agent-from-scratch/course-checkpoints/06-session-reliability
python steps/l21_session_turn_run.py
python steps/l22_context_budget.py
python steps/l23_checkpoint_resume.py
python steps/l24_retry_config.py
python demo.py
```

所有持久化都在临时目录，Retry 测试不真实等待，也不访问网络。本模块不宣称 JSON Checkpoint 实现分布式 exactly-once，而是明确展示失败窗口和 Tool 幂等责任。完成实验后查看 [模块练习参考答案](模块练习参考答案.md)，最后执行 [模块验收与面试](模块验收与面试.md)。
